# WispTerm v1.40.1

> Patch release. Codex subscription chat no longer fails with
> "Store must be set to false". No configuration migration is required.

## Fixed

- **Codex subscription requests (#645).** Calls to
  `chatgpt.com/backend-api/codex/responses` now send `store: false` and
  `stream: true`, and each message is a typed Responses item. The event
  stream is read to the end, so the reply and any tool call still arrive
  as one result when chat streaming is off.

## Compatibility

- Existing settings and workflows continue to work unchanged.
- This is a desktop-only release; WispTerm Remote web console versions are
  not changed.

# WispTerm v1.40.1（中文）

> 补丁发布。Codex 订阅对话不再返回 “Store must be set to false”。
> 无需迁移配置。

## 修复

- **Codex 订阅请求（#645）。** 发往
  `chatgpt.com/backend-api/codex/responses` 的请求现在带 `store: false`

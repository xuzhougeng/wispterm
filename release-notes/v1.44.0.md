# WispTerm v1.44.0

> Terminal query replies that unblock grok CLI (and help ConPTY), a Windows
> titlebar button for the Command Center, and UI labels that stay inside
> their rows. No configuration migration is required.

## Added

- **Command Center button in the Windows titlebar (#681).** macOS already
  reaches the Command Center from View › Open Command Center; Windows only had
  Ctrl+Shift+P. A magnifier button left of the Copilot button now toggles it,
  and the button is carved out of the draggable caption strip so the click
  reaches the app instead of starting a window drag.

- **Illustrated tutorial for creating and editing LLM profiles.** The Chinese
  tutorial page on the website walks through the New Session entry, the AI
  profile form, and editing an existing profile with macOS screenshots.

## Fixed

- **grok CLI no longer sits on a blank screen on macOS and Linux (#683).**
  WispTerm answered the Kitty keyboard query (`CSI ? u`) but never the primary
  device attributes query (`CSI c`). grok sends both, treats the Kitty reply as
  proof the terminal responds, and then waits for DA1 with no timeout. WispTerm
  now answers DA1/DA2/DA3 the way Ghostty does (`CSI ? 62 ; 22 c`) and reports
  `WispTerm <version>` to XTVERSION. Codex and Pi were unaffected because they
  do not wait for DA1. On Windows the modern ConPTY also sends DA1 to its host
  terminal and gates scroll optimizations on the reply, so this matters for
  SSH-hosted TUIs there too (see #680).

- **UI labels stay inside their layout bounds (#682).** Settings, Skill
  Center, Sync, the password store, the New Session launcher, the Command
  Center list, startup shortcuts, and Agent History no longer let long field
  names or values spill past their column. Rows now give each label its
  measured width when it fits, reserve up to half the row for the primary
  label under pressure, and ellipsize the rest; hovering an ellipsized label
  reveals the full text in a frame-local hint.

- **macOS release notarization retries ticket validation.** Apple's stapler
  step is retried with a short backoff instead of re-signing and re-notarizing
  the whole package on each failure.

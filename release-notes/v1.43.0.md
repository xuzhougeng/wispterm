# WispTerm v1.43.0

> Click to place the caret in the AI composer, a much cheaper AI Chat repaint,
> a Windows IME fix, and a best-effort macOS 12 build. No configuration
> migration is required.

## Added

- **Click to place the caret in the AI composer (#678).** In the Copilot
  sidebar and the full AI Chat tab, a left click in the input box moves the
  caret to the clicked position; clicking past the middle of a character puts
  the caret after it. Hit testing shares the composer's wrap rule with the
  painter, so the caret lands where the text is drawn, including Chinese and
  other multi-byte text. Drag selection and Shift+click are not included.

- **macOS 12 Monterey, best-effort (#677).** The macOS app is now built for
  macOS 12.0 instead of 13.0, and CI rejects any bridge code that uses an API
  newer than 12.0 without an availability guard. No CI runner can launch
  macOS 12, so it is not tested there; macOS 13 Ventura and later remain the
  supported floor. Building still requires macOS 13+.

## Changed

- **Default AI model is `deepseek-flash` with Vision on.** DeepSeek's
  current Flash model accepts image input, so a new profile on it starts with
  Vision enabled. Quick Configure AI now creates or refreshes a single
  `DeepSeek Flash` profile used for both the default and subagent profiles,
  and no longer adds a `deepseek-v4-pro` profile. Existing profiles are left
  untouched; profiles saved without a Vision setting keep Vision off.

## Improved

- **AI Chat repaints are much cheaper (#676).** Each message is measured once
  per frame through a cached wrap index, and only the lines that can reach
  the viewport are painted, so a long tool card no longer makes every cursor
  blink, keystroke or scroll walk the whole transcript. On macOS, UI glyph
  and quad drawing is batched on Metal as it already was on OpenGL. On a tab
  holding a 3000-line `run_command` card, the ReleaseFast draw time per frame
  went from about 27 ms to under 1 ms.

## Fixed

- **Windows IME candidate list no longer covers the text you are typing
  (#679).** WispTerm draws the composition text inline and hides the IME's
  own composition window; the Windows 11 Microsoft Pinyin IME then ignored
  the candidate position and anchored its list on the caret row. WispTerm now
  tells the IME the caret cell rectangle to keep clear of, so the list opens
  below the row (or above it when there is no room).

- **Render loop no longer spins on AI Chat, Settings and other paneless tabs
  (#675).** A pending one-shot layout request was never consumed on tabs
  without a terminal pane, so every main-loop iteration re-rendered until a
  terminal tab was shown. With a large AI tool card this pinned the main
  thread and starved shortcuts such as Cmd+Shift+P.

- **macOS release notarization retries ticket validation.** Apple's stapler
  validation step is retried up to five times before the release build fails.

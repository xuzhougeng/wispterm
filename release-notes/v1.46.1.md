# WispTerm v1.46.1

> Follow-ups to the Magpie model connection: image input works for the
> managed profile, Magpie's reasoning, output-limit and protocol settings are
> honored, and a Magpie session can switch reasoning effort from the header
> or `/effort` without editing `magpie.json`. A v1.46.0 Windows install picks
> this release up through the in-place updater; the titlebar shows **Update**
> and a restart finishes it. No configuration migration is required.

## Added

- **Switch reasoning effort in a Magpie session (#699).** The Agent / Copilot
  header shows the current reasoning level beside the model name; click it to
  move to the next level the model supports. `/effort` (Chinese alias
  `/推理强度`) lists the current and supported levels, and `/effort <level>`
  switches this session, refusing levels the model does not list. The choice
  applies from the next request and is not written to `magpie.json`,
  `ai_profiles` or the native config. Explicit `thinking: false` offers no
  levels.
- **Magpie reasoning, output-limit and protocol settings (#698).** The managed
  profile reads optional user-owned fields in `magpie.json`: `thinking`,
  `reasoningEffort`, `maxTokens`, `protocol` (`chat_completions` or
  `responses`), `stream`, `agent` and `systemPrompt`. When Magpie advertises
  the model's supported efforts WispTerm picks `medium`, then `high`, then the
  first listed level; `maxTokens` defaults to the model's advertised output
  limit (8192 when unknown) and is capped at it. The profile form labels the
  cap **Max Output Tokens** and shows the model's context capacity in the
  hint. See `docs/magpie.md` in the repository.

## Fixed

- **Image input for Magpie-managed profiles (#697).** Image attachments are
  enabled by default for the managed profile again; pick an image-capable
  model in Magpie to use them, or set `"vision": false` to turn them off.
- **An explicit `reasoningEffort: "auto"` is preserved (#698)** instead of
  being replaced by a chosen level, so the provider keeps its own reasoning
  choice.
- **The conversation header lays out from measured widths at any scale
  (#699).** On Retina the effort chip could run under the Agent label
  ("mediuAgent"), compact sidebar errors such as "Missing API key. Click to
  configure" drew nothing, "Queued: N" covered the permission label, and the
  stop button and collapse arrows were cut to fixed 1x widths. Render and
  every header hit test now share one measured row layout.

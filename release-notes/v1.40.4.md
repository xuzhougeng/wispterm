# WispTerm v1.40.4

> Patch release. Function keys reach the shell, research tools can use
> their own proxy, and Ctrl+click selects a whole Chinese filename. The
> first WSL split no longer freezes the window. No configuration
> migration is required.

## Added

- **Function keys (#653, #658).** F1–F12, with Shift, Ctrl, and Alt, are
  sent to the PTY with Ghostty's default sequences. Unmodified F2 is
  `ESC O Q`. Windows, the SDL backend, and macOS all use that encoder.
  On macOS the physical F-keys are mapped before AppKit turns them into
  function-key characters.

- **Pi (#655).** Pi is a terminal agent next to Codex and Claude Code.
  OSC 7748 accepts `app=pi`, and launching Pi uses the same terminal
  routing.

- **Research Tools Proxy (#654, #658).** Settings → AI & Integrations
  adds **Use Research Tools Proxy** (使用研究工具代理), off by default.
  When it is on, Web Search, Web Read, and PubMed — including the agent
  tools — use **Research Tools Proxy**. An empty address inherits the AI
  proxy address above, even when **Use AI proxy** is off. A custom
  address overrides it. An empty inherited address uses the system proxy.
  Config keys: `research-use-proxy` and `research-proxy`.

- **Terminal capability advertisement.** Local and WSL child processes
  advertise `TERM_PROGRAM=ghostty` and `COLORTERM=truecolor`, so programs
  such as Pi and Claude Code can enable Kitty images and the Kitty
  keyboard protocol. SSH stays unchanged unless
  `ssh-advertise-terminal-capabilities` is set to `true`.

## Fixed

- **Chinese filenames on Ctrl+click (#657).** The hover underline and
  Ctrl+click cover the whole name, including a name such as
  `分析内容.docx`. Double-click no longer stops after every Han
  character. An `ls` directory written in Chinese stays one path. A
  colon or URL after Chinese prose is still a separate token.

- **First WSL split (#652).** Splitting a WSL pane no longer blocks the
  window on the first call. The split launches with `wsl.exe --cd` and
  does not spawn `wsl.exe --list` or touch `\\wsl.localhost` just to
  invent a Windows working directory.

## Compatibility

- Existing settings keep working. `research-use-proxy` defaults to off,
  so Web Search, Web Read, and PubMed do not start using a proxy until
  you turn that setting on.
- F1–F12 now produce terminal sequences. They were previously dropped.
- Local and WSL programs see `TERM_PROGRAM=ghostty`. SSH does not, unless
  you opt in.
- This is a desktop-only release. The WispTerm Remote web console version
  is unchanged.

# WispTerm v1.40.4（中文）

> 补丁发布。功能键会送到终端，研究工具可以单独走代理，Ctrl+点击能选中
> 完整的中文文件名。WSL 第一次分屏不再卡住窗口。无需迁移配置。

## 新增

- **功能键（#653，#658）。** F1–F12 以及 Shift、Ctrl、Alt 组合会按
  Ghostty 的默认序列发给 PTY。未按修饰键的 F2 是 `ESC O Q`。Windows、
  SDL 和 macOS 走同一套编码。macOS 会先把物理功能键映射过去，再交给
  这套编码。

- **Pi（#655）。** Pi 与 Codex、Claude Code 一样被识别为终端代理。
  OSC 7748 接受 `app=pi`，启动 Pi 也走同一套终端路由。

- **研究工具代理（#654，#658）。** 设置 → AI 与集成新增
  **使用研究工具代理**，默认关闭。打开后，网页搜索、网页阅读和 PubMed
  （含智能体工具）使用 **研究工具代理**。地址留空时继承上方的 AI 代理
  地址，即使 **使用 AI 代理** 是关闭的。填写地址则只给研究工具用。
  继承到的地址如果也是空的，就使用系统代理。配置项是
  `research-use-proxy` 和 `research-proxy`。

- **终端能力通告。** 本地和 WSL 子进程会通告
  `TERM_PROGRAM=ghostty` 与 `COLORTERM=truecolor`，因此 Pi、Claude Code
  这类程序可以打开 Kitty 图像和 Kitty 键盘协议。SSH 保持原样，除非把
  `ssh-advertise-terminal-capabilities` 设为 `true`。

## 修复

- **Ctrl+点击中文文件名（#657）。** 悬停下划线和 Ctrl+点击会覆盖整个
  名字，例如 `分析内容.docx`。双击不再在每个汉字后断开。`ls` 列出的
  中文目录仍是一整段路径。中文后面的冒号或网址仍然单独成词。

- **WSL 第一次分屏（#652）。** 拆分 WSL 面板不再在第一次调用时卡住
  窗口。分屏用 `wsl.exe --cd` 启动，不会为了编造一个 Windows 工作目录
  而去运行 `wsl.exe --list` 或访问 `\\wsl.localhost`。

## 兼容性

- 现有设置继续有效。`research-use-proxy` 默认关闭，因此在你打开这项
  之前，网页搜索、网页阅读和 PubMed 不会改走代理。
- F1–F12 现在会向终端发送序列。以前这些键会被丢掉。
- 本地和 WSL 程序会看到 `TERM_PROGRAM=ghostty`。SSH 不会，除非你明确打开。
- 这是仅桌面端的发布。WispTerm Remote 网页控制台版本不变。

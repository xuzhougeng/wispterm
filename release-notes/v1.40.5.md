# WispTerm v1.40.5

> Patch release. Workbench page shortcuts can be remapped, Pi sessions can
> come back after a restart, and Windows D3D11 presents only the rows that
> changed. Agent question cards scroll sideways when an option is wider than
> the card. No configuration migration is required.

## Added

- **Scoped workbench shortcuts.** File Explorer, Agent History, AI History,
  Memory Center, Conversation Center, Port Forwarding, and Skill Center
  shortcuts are `keybind` entries. A scope keeps the same key available on
  different pages, for example `keybind = file-explorer:r=file_explorer_rename`
  and `keybind = port-forwarding:r=port_forwarding_restart`. `keybind = clear`
  also removes those scoped defaults. The default keys are unchanged.
  Navigation, text entry, and terminal-local keys stay with the focused
  editor or terminal.

- **Pi session restore (#660).** With `restore-tabs-on-startup = true`,
  WispTerm saves the Pi JSONL session path and relaunches it with
  `pi --session` on the next start. Local, WSL, and SSH sessions are
  covered. A local path that does not belong to this machine is skipped.
  Closing the window asks a capable Pi session to run `/wispterm-shutdown`
  and waits up to about 2.5 seconds before the normal PTY teardown.

## Improved

- **Windows D3D11 frame pacing.** The native swap chain uses a waitable
  object so Present does not stall the next frame. When a terminal-only
  frame can prove which rows changed, Present1 updates that rectangle.
  Cursor, atlas, layout, and overlay frames still present the full frame.
  Scrolling still presents the full frame.

## Fixed

- **Agent question cards (#661, #662).** When `ask_user` shows a question
  or option wider than the card, a horizontal scrollbar appears under the
  options. Drag the thumb or click the track to read the full text. Using
  the scrollbar does not choose an option. Each conversation keeps its own
  position, and a new question starts at the left edge.

- **Pi history paths.** A Pi session id falls back to the file name even
  when the path uses the other platform's separator, so a Windows path
  scanned on Linux (and the reverse) still yields the session id.

## Compatibility

- Existing settings keep working. Default shortcuts stay in place until
  you add a `keybind` line.
- Pi sessions are restored only when `restore-tabs-on-startup` is already
  on. It still defaults to off.
- This is a desktop-only release. The WispTerm Remote web console version
  is unchanged.

# WispTerm v1.40.5（中文）

> 补丁发布。工作台页面的快捷键可以改绑，Pi 会话可以在重启后恢复，
> Windows 的 D3D11 只刷新有变化的行。智能体提问卡片在选项比卡片宽时
> 可以横向滚动。无需迁移配置。

## 新增

- **带作用域的工作台快捷键。** 文件管理器、智能体历史、AI 历史、记忆中心、
  对话中心、端口转发和技能中心的快捷键都进入 `keybind`。作用域让同一个键
  在不同页面做不同的事，例如
  `keybind = file-explorer:r=file_explorer_rename` 和
  `keybind = port-forwarding:r=port_forwarding_restart`。
  `keybind = clear` 也会清掉这些作用域默认值。默认按键不变。导航、文本输入
  和终端本地按键仍由当前焦点里的编辑器或终端处理。

- **Pi 会话恢复（#660）。** 打开 `restore-tabs-on-startup = true` 后，
  WispTerm 会保存 Pi 的 JSONL 会话路径，下次启动用 `pi --session` 重新打开。
  本地、WSL 和 SSH 都包括。不属于这台机器的本地路径会被跳过。关闭窗口时，
  支持该命令的 Pi 会话会先收到 `/wispterm-shutdown`，最多等待约 2.5 秒，
  然后再走原来的 PTY 关闭。

## 改进

- **Windows D3D11 帧节奏。** 原生交换链使用可等待对象，Present 不再挡住
  下一帧。终端画面能证明哪些行变了时，Present1 只更新那一块矩形。光标、
  图集、布局和浮层仍然整帧呈现。滚动也仍然整帧呈现。

## 修复

- **智能体提问卡片（#661，#662）。** `ask_user` 的问题或选项比卡片宽时，
  选项下方会出现横向滚动条。拖动滑块或点击轨道可以读完全文。使用滚动条
  不会选中选项。每个对话记住自己的位置，新问题从左端开始。

- **Pi 历史路径。** Pi 会话在缺少 id 时回退到文件名。路径即使用了另一套
  平台的分隔符，也能取出会话 id，因此在 Linux 上扫描 Windows 路径（以及
  反过来）仍然有效。

## 兼容性

- 现有设置继续有效。在你添加 `keybind` 之前，默认快捷键保持不变。
- 只有已经打开 `restore-tabs-on-startup` 时才会恢复 Pi 会话。这项仍默认关闭。
- 这是仅桌面端的发布。WispTerm Remote 网页控制台版本不变。

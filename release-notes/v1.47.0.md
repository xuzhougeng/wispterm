# WispTerm v1.47.0

> Tabs running a terminal agent now show idle / run / ask / done without a
> hook installed, `wisptermctl` can wait on and drive those agents, Copilot
> and the File Explorer share a switchable right dock, and a phone on the
> same Wi-Fi can reach WispTerm directly over the LAN. This release also
> carries the fixes from a whole-repo audit, including three that keep API
> keys and other secrets out of the agent history and tool cards. A v1.46.x
> Windows install picks this release up through the in-place updater; the
> titlebar shows **Update** and a restart finishes it. No configuration
> migration is required.

## Security

- **The API key is no longer written to the agent history file (#720).**
  Saved sessions stored the key in plain text. It is now always written
  empty, so an existing file is scrubbed on its next save. A restored
  session takes its key from the saved AI profile with the same base URL and
  model; a session whose profile was deleted comes back without a key.
- **`wispterm_config` no longer returns credential values to the model
  (#718).** `jina-api-key`, `remote-session-key` and `feishu-app-secret`
  report only whether they are set, and `set` does not echo them, so they do
  not reach the tool card or saved history.
- **The AI profiles file is created owner-only (#718).** It holds API keys
  and was world-readable on macOS and Linux; it is now `0600`.
- **Approval and deny-list gaps in the agent tools are closed (#720).**
  `webread` on a local file refuses deny-listed paths and asks for approval
  outside full mode. `copy_file` gates its source like `read_file` and its
  destination like `write_file`. `tab_new` with a dangerous or deny-listed
  command asks in auto mode too. The `mcp_config add` card shows the full
  command line. Deny rules match Windows paths, fold case on Windows and
  macOS, and always deny the directory the rules file lives in.
- **Agent `tab_close` no longer falls back to the active tab (#718).** A
  surface id or title that no longer matched closed the tab the user was
  looking at; it now reports that the tab was not found.

## Added

- **Screen-based agent status (#708).** A tab running Claude Code, Codex,
  Gemini CLI, Copilot CLI, Cursor, Kimi, OpenCode, Pi, Qwen or another of the
  22 supported agents shows idle / run / ask / done and raises attention
  notifications without a hook installed. Detection uses herdr's manifests
  (Apache-2.0, vendored unchanged). OSC 7748 hook markers stay authoritative
  where installed. Turn it off with `agent-screen-detection = false`. An
  agent started by hand inside an SSH tab is recognized only when it is
  Claude Code; see `KNOWN_ISSUES.md`.
- **Agent automation in `wisptermctl` (#709, #710).** `agent-state` reports
  a pane's agent and state. `wait-agent --until STATE...` waits for a state.
  `prompt --wait` sends a prompt and waits for the agent to finish.
  `spawn --kind AGENT --split right|down --wait-ready` starts an agent in a
  split. `wait-for --regex` waits for screen text. `send-keys -t <id>
  <key>...` sends named keys and chords (`enter`, `shift+tab`, `ctrl+c`),
  encoded from the pane's live keyboard state so they match a real keypress.
  See `docs/agent-control.md` for commands and exit codes.
- **Right dock for Copilot and the File Explorer (#705).** The right edge is
  one dock with a tab row that switches between Copilot and Files. Open
  state and the selected panel are per tab; the width is shared and
  remembered. `file-explorer-position = left` keeps the explorer in the old
  left panel.
- **Toolbar buttons appear on hover (#703).** The sidebar toggle, settings,
  help, Copilot, command center and new-tab buttons stay hidden until the
  pointer is over the titlebar or tab sidebar, then fade in. Caption
  buttons, the title, SSH latency and the Update pill always show.
  `window-show-toolbar = always` restores the always-visible buttons.
- **Remote category in Settings (#713).** Edit `remote-enabled`,
  `remote-server-url`, `remote-device-name` and `remote-session-key` (masked
  once saved), plus `lan-stream-enabled` on macOS. Changes apply after a
  restart.
- **LAN access from the phone app, macOS only (#712, #714).** With
  `lan-stream-enabled = true`, WispTerm advertises itself over Bonjour and a
  phone on the same Wi-Fi can view the window and drive the terminal and AI
  Chat without the public relay. `lan-stream-source = display` streams a
  whole display instead of the window (needs the Screen Recording
  permission); `lan-stream-display` picks the display and `lan-stream-fps`
  caps the frame rate (1–30, default 4). The protocol is documented in
  `docs/configuration.md`.
- **Agent transcripts and approvals for remote clients (#711).** A pane
  running Claude Code or Codex sends the tail of the agent's conversation
  and the approval menu on screen, so a phone can show it as a chat. A
  pending in-app AI approval can be answered from the phone with `y` / `n`.

## Changed

- **Agent question cards (#700, #701).** Text on an `ask_user` card can be
  selected and copied, and the composer caret stays visible while the card
  waits for a typed answer. The card hint and nearby card strings are
  localized. An "Answered" card stays in the transcript, and time spent
  waiting for an answer is reported as "answer wait" instead of counting
  toward "Done in" and token/s.
- **Copilot waits on the agent's own state (#709).** `terminal_repl_exec`
  against an agent pane keeps waiting through quiet thinking, returns at
  once on a decision prompt and finishes when the agent goes idle.

## Fixed

### Terminal and rendering

- **Large grids no longer render blank past 30,000 cells (#720).** A
  maximized window on a large display with a small font left the rest of the
  grid empty.
- **The last output of a command paints in an unfocused window (#702).**
  Output that arrived between the frame snapshot and present could stay
  unpainted until an unrelated mouse event.
- **Scrolling in vim, less or a tmux status line no longer forces a full
  repaint on every later frame (#719).**
- **A D3D11 startup failure is reported instead of crashing (#719).**
- **Closing a tab no longer aborts the app (#715, #718).** Several tab and
  surface fields were left uninitialized on some creation paths.
- Focus lands on the right pane after closing a split, split dividers are
  grabbed where they are drawn, and a restored session focuses the tab that
  was active (#718).
- Wheel events past column 222 are reported in UTF-8 mouse mode (#718).

### Input

- **AltGr characters work in every text field on Windows (#718).** `@`,
  `{`, `[` and `\` on many layouts were dropped everywhere except Password
  Store and Sync.
- **Emoji-panel input on Windows is no longer lost (#718).**
- **Overlays opened by a shortcut appear at once (#718).** The session
  launcher and the Copilot conversation picker used to paint only on the
  next cursor blink or mouse move; tab rename and file-explorer inline edits
  had the same delay.
- A large CJK or emoji paste into a tmux pane no longer arrives as stray
  bytes (#719).

### SSH and files

- **The file explorer and SCP work through a jump host (#720).** A session
  reached with `ProxyJump` could open a shell but not list or transfer
  files.
- **Rename, new and delete in the file explorer no longer touch the local
  disk in SSH or WSL mode (#719).** Deleting `/tmp/build` on an SSH host
  removed the local `/tmp/build`. These three actions are local-only for
  now and say so.
- Long remote paths no longer overflow the SCP path buffer, the OpenSSH
  config import no longer assigns `Match` settings to the previous `Host`,
  and a user, host or profile name starting with `-` is rejected (#719).
- The local HTML preview server no longer serves files from a sibling
  directory (#719).

### Config

- **A `config-file` that includes itself no longer crashes at startup
  (#719).** Nesting is capped at 8.
- **`desktop-notifications`, `confirm-close-running-program` and
  `agent-screen-detection` set to `false` are honored at startup (#718)**,
  not only after a hot reload.
- `window-height = 0` / `window-width = 0` mean auto as documented, and
  changing a setting from the Settings page no longer removes the blank
  lines in the config file (#719).
- The first config change on Windows no longer corrupts the stack (#718).
  This fix was compile-checked only and has not been run on Windows.

### AI and agents

- **Text after a bare `<` is no longer dropped (#718).** "if x < 10 then"
  rendered as "if x" in AI replies, Copilot cards, What's New and the
  markdown preview.
- `/loop` with a very large interval no longer aborts the app, a stream
  chunk carrying `"error": null` no longer ends the reply as an error,
  subscription (OAuth) chats get a title, and Anthropic usage reports its
  totals and cache fields (#718).
- `memory_save` rejects the name `MEMORY` instead of being overwritten by
  the index file (#718).
- Local Pi sessions restore on macOS and Linux (#718).
- Chat bridges accept a newline or tab after a command (`/ai`, `/term`),
  and WeChat push text no longer cuts mid-character (#719).
- Status toasts, the macOS update prompt, What's New and Conversation
  Center previews no longer split multi-byte characters (#718).

### Platform

- **macOS / Linux: closing a tab no longer leaves a zombie shell, and child
  processes no longer inherit other tabs' PTYs (#718).**
- macOS: hover state no longer sticks after the pointer leaves the window
  (#703, #718).
- Windows: kitty graphics from programs inside a session (yazi previews)
  are still dropped by ConPTY. The cause and workarounds are now documented
  in `KNOWN_ISSUES.md` (#706, closes #704).

## Internal

- The four release workflows publish through one script, so parallel jobs
  on the same tag no longer fail racing to create the GitHub release.
- CI treats embedded docs, release notes and skill-eval fixtures as code.
- Removed the unreachable horizontal tab strip, the per-surface FBO path,
  the `gl_init` shims and the unused `pkg/opengl` package.
- New source guards: `tab_state_init_guard` and a frame-dirty ordering
  guard for the main loop.

# WispTerm v1.40.2

> Patch release. OpenCode Go can be used as an AI profile, and the Chinese
> tutorial explains Codex, Kimi, xAI, and OpenCode Go sign-in. No
> configuration migration is required.

## Added

- **OpenCode Go profiles.** Protocol `opencode-go` uses the Go API key from
  the OpenCode Zen console, not a device-code login. The default endpoint is
  `https://opencode.ai/zen/go/v1` and the default model is `glm-5.3-flash`.
  Each conversation sends a stable `x-opencode-session`, and the client
  identifies itself as `wispterm/<version>`. The model id selects the wire
  format: chat completions, Responses, or Messages. Profiles whose base URL
  is already `https://opencode.ai/zen/go` get the same session header.

- **Chinese subscription tutorial.** `tutorial.zh.html` has a section for
  Codex, Kimi, xAI, and OpenCode Go: where to sign in, when an API key is
  enough, and how OpenCode Go models map to endpoints.

## Compatibility

- Existing settings and workflows continue to work unchanged.
- This is a desktop-only release; WispTerm Remote web console versions are
  not changed.

# WispTerm v1.40.2（中文）

> 补丁发布。可以把 OpenCode Go 配成 AI 配置。中文教程说明了 Codex、Kimi、
> xAI 和 OpenCode Go 的登录方式。无需迁移配置。

## 新增

- **OpenCode Go 配置。** 协议 `opencode-go` 使用 OpenCode Zen 控制台里的
  Go API 密钥，不走设备码登录。默认地址是 `https://opencode.ai/zen/go/v1`，
  默认模型是 `glm-5.3-flash`。每个对话会带上稳定的 `x-opencode-session`，
  客户端标识为 `wispterm/<版本>`。模型 ID 决定接口：聊天补全、Responses
  或 Messages。接口地址已经是 `https://opencode.ai/zen/go` 的配置也会带上
  同一个会话头。

- **中文订阅教程。** `tutorial.zh.html` 增加了 Codex、Kimi、xAI 和
  OpenCode Go 一节，说明何时登录、何时填写密钥，以及 OpenCode Go
  模型对应哪个接口。

## 兼容性

- 现有设置和工作流无需改动。
- 这是仅桌面端的发布；WispTerm Remote 网页控制台版本不变。

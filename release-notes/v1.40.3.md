# WispTerm v1.40.3

> Patch release. The new-session menu can open Port Forwarding, Memory
> Center, and Settings. WSL and SSH previews keep their source after a
> restart, and SimSun draws from its bitmap strikes. No configuration
> migration is required.

## Added

- **Workbench pages in the new-session menu (#646).** The tab-strip **+**
  menu and **Ctrl+Shift+T** (**Cmd+Shift+T** on macOS) list Port Forwarding,
  Memory Center, and Settings with Shell, SSH, and Copilot. Settings focuses
  the Settings tab that is already open. Port Forwarding and Memory Center
  open a new tab. The Memory Center title follows the UI language, so Chinese
  shows 记忆中心.

## Fixed

- **WSL and SSH working directories on Windows (#648).** An OSC 7 directory
  such as `/home/user/project` stays a Unix path. Only drive and UNC paths
  change separators, so a Windows preview path such as `/D:\dir` still opens.
  Relative previews, the file explorer, and new tabs in a WSL or SSH session
  use that directory again.

- **SimSun and live font changes (#649, #647).** SimSun and NSimSun 1-bit
  bitmap glyphs expand to coverage instead of being copied as gray bytes, so
  CJK text is no longer a diagonal hatch. Changing the font family, style,
  CJK family, or fallback reloads the face without a restart. The font list
  puts the default family first, sorts the rest, and filters as you type. The
  default row is labeled Default / 默认.

- **Restored previews keep their WSL or SSH source (#650).** With
  restore-tabs-on-startup, an image or Markdown preview reopens on the same
  local, WSL, or SSH source. The SSH password comes from the saved host
  profile and is not written into the session file. Older session files
  without a source still open that preview as local.

## Compatibility

- Existing settings and workflows continue to work unchanged.
- This is a desktop-only release; WispTerm Remote web console versions are
  not changed.
- Session files from older versions still restore. Previews in those files
  open as local until the session is saved again from this version.

# WispTerm v1.40.3（中文）

> 补丁发布。新建会话菜单可以打开端口转发、记忆中心和设置。WSL 与 SSH
> 预览在重启后仍走原来的来源，宋体按点阵字形绘制。无需迁移配置。

## 新增

- **新建会话菜单里的工作台页面（#646）。** 标签栏的 **+** 以及
  **Ctrl+Shift+T**（macOS 为 **Cmd+Shift+T**）在 Shell、SSH、Copilot
  之外列出端口转发、记忆中心和设置。设置会切到已经打开的设置标签。端口转发
  和记忆中心会新开一个标签。记忆中心的标题跟随界面语言，中文显示为「记忆中心」。

## 修复

- **Windows 上的 WSL 与 SSH 工作目录（#648）。** OSC 7 报告的
  `/home/user/project` 保持 Unix 路径。只有盘符路径和 UNC 路径才会改分隔符，
  因此 `/D:\dir` 这类 Windows 预览仍然能打开。WSL 和 SSH 会话里的相对路径
  预览、文件浏览器和新标签重新使用这份目录。

- **宋体与即时换字体（#649，#647）。** 宋体和 NSimSun 的 1 位点阵会展开成
  覆盖率，不再被当成灰度字节拷贝，中文不再画成斜线。更换字体家族、样式、
  中日韩字体或回退字体后立即重新加载，不必重启。字体列表把默认字体放在最前，
  其余按名称排序，输入即可筛选。默认一行标为 Default / 默认。

- **恢复的预览保留 WSL 或 SSH 来源（#650）。** 开启启动时恢复标签后，图片或
  Markdown 预览仍从原来的本地、WSL 或 SSH 打开。SSH 密码从已保存的主机配置
  填入，不会写进会话文件。没有来源字段的旧会话仍按本地预览打开。

## 兼容性

- 现有设置和工作流无需改动。
- 这是仅桌面端的发布；WispTerm Remote 网页控制台版本不变。
- 旧版本写出的会话文件仍可恢复。其中的预览会按本地打开，直到用这个版本
  重新保存会话。
